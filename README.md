# Serene Spend

Create a modern personal finance tracker app with a clean, minimal design. Include features for logging income and expenses, categorizing transactions (e.g., food, transport, bills, entertainment), viewing a monthly spending summary with a simple bar or pie chart, and setting a monthly budget with a progress indicator that changes color as you approach the limit. Add a dark mode toggle. Use a calming teal-and-charcoal color scheme with rounded cards and generous whitespace. The layout should have a sidebar for navigation (Dashboard, Transactions, Budgets, Settings) and a main content area showing the selected view. Keep the interface uncluttered — favor clear typography and simple icons over dense tables
